# n8n (workflow automation)

Deployed by the `n8n/` Terraform component on 2026-11-13. It's plain
Kubernetes resources (no Helm chart) in the `n8n` namespace:

- `kubernetes_deployment_v1.n8n`: one replica of
  `docker.n8n.io/n8nio/n8n:2.47.7` (what `stable` pointed to at install),
  running as uid/gid 1000. Strategy is `Recreate` so the old pod releases the
  RWO volume before the new one starts.
- `kubernetes_persistent_volume_claim_v1.data`: PVC **`n8n-data`**, 5Gi on
  `longhorn`, mounted at `/home/node/.n8n`. It holds the SQLite database
  (workflows, credentials, execution history), config and binary data.
- `kubernetes_secret_v1.n8n`: `N8N_ENCRYPTION_KEY`, generated by
  `random_password.encryption_key`.
- `kubernetes_service_v1.n8n` (port 80 → 5678) and
  `kubernetes_ingress_v1.n8n` (Traefik).

## Address: `http://n8n.192.168.39.20.nip.io/`

There's no local DNS or domain yet, so the Ingress host uses
[nip.io](https://nip.io): a public wildcard DNS service where
`<anything>.<ip>.nip.io` resolves to `<ip>`. Here that's the control-plane VIP,
where Traefik answers on port 80 (ServiceLB binds it on every node). n8n itself
doesn't need nip.io. Traefik routes by hostname, and n8n needs its own URL
(`N8N_HOST`, `WEBHOOK_URL`) to build webhook and OAuth callback links.

Caveats:

- Resolving the name needs internet DNS. Some routers and DNS filters (e.g.
  Pi-hole with rebind protection) block public names that resolve to private
  IPs, so it may fail on some devices.
- To move to a real name, add a DNS record pointing at `192.168.39.20` and set
  `host` in `n8n/terraform.tfvars`, then apply. That updates the Ingress and
  n8n's URL together.

It's plain HTTP, so `N8N_SECURE_COOKIE=false`. Otherwise browsers drop the
login cookie. Webhook URLs are LAN-only, so external services can't call them.

## Encryption key: keep the Terraform state

n8n encrypts stored credentials with `N8N_ENCRYPTION_KEY`. The key exists
only in the Secret and in `n8n/terraform.tfstate`. If the state is lost and
Terraform regenerates the key, existing credentials in the PVC become
unreadable. Back up the state (or the key) along with the data.

## First run / operations

- On first visit n8n asks you to create the owner account. Nothing is
  pre-seeded.
- Upgrade: change `image` in `terraform.tfvars` to a newer pinned tag and
  apply. n8n migrates the SQLite DB on startup, so take a Longhorn snapshot of
  `n8n-data` first.
- Logs: `kubectl -n n8n logs deploy/n8n`.
- Health: `curl http://n8n.192.168.39.20.nip.io/healthz` returns 200.
- Single replica on SQLite only. Scaling out needs Postgres and n8n's queue
  mode (Redis + workers), which this doesn't set up.
